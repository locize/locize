Node removed while highlighted (orphaned highlight boxes):

Hover the line below and keep the mouse still - it removes itself 3 seconds later. The highlight box (and its ribbon) must disappear together with the node. They used to stay behind permanently: the store dropped the item without removing its boxes, so nothing referenced them any more and no amount of mouse movement could ever clear them. Frameworks that re-render (React, Angular, Vue) hit this on every re-render that replaces a highlighted element.

Hovering behind the editor popup:

Drag the editor popup over the line below, so the popup covers part of it. With the cursor over the popup, nothing on the page may highlight - the popup is editor chrome and counts as an occluder, exactly like the modal backdrop above. It used to highlight anyway, because the popup carries the same data-i18next-editor-element marker as the editor's own hover overlays. With the cursor on a still-visible part of the line it must highlight, even when the line's centre is the bit hidden under the popup. Hovering a highlighted line's ribbon must still keep the highlight, as before.
